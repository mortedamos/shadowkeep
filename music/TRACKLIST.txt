=====================================================================
  SHADOWKEEP  -  MUSIC TRACK LIST  (with Suno prompts + leitmotifs)
=====================================================================

HOW THIS WORKS
--------------
1. Create each track below and save it in THIS folder (music/) using the
   FILE NAME shown. The game loads this very file at startup and plays
   whatever it finds - tracks that don't exist yet are simply skipped
   (the game stays quiet instead of crashing), so you can add them one
   at a time and just refresh the browser.
2. Formats: .mp3, .ogg or .wav. If "title.mp3" is missing the game also
   tries "title.ogg" and "title.wav", so use whichever you prefer.
3. LOOP tracks repeat forever - end them so they loop cleanly (the end
   should flow back into the start).  STING tracks play once.
4. Want different file names?  Edit the FILE NAME column below - the game
   reads it.  Keep the ID column unchanged (the code refers to the IDs).
   File names may contain spaces and brackets, so you can point a track at a
   Suno download as-is, e.g. change the FILE NAME cell of the title line to:
       Tolling Church Organ - usesuno.com(1).mp3
   (copy the name exactly).  Refresh the browser after changing this file.
5. Mix level: aim for roughly -14 LUFS / peaks under -1 dB.  The game has
   its own volume slider (Pause menu).

LINE FORMAT  (lines starting with # are comments and are ignored by the game)
------------------------------------------------------------------
ID | FILE NAME | TYPE | WHERE IT PLAYS | MOOD / DIRECTION

#                 into this line (Suno v4.5 / v5 allow ~1000 characters here).
#   SUNO SHORT:   the same idea in under 200 characters, for older Suno versions whose
#                 style box is capped at 200.
#   SUNO LYRICS:  paste into the Lyrics box (structure tags only - these are instrumentals)
#   MOTIFS:       which leitmotifs appear in the track (see below)


=====================================================================
  THE LEITMOTIFS  -  the musical DNA that ties the whole score together
=====================================================================
Every track quotes at least one of these five short themes, re-orchestrated
for the mood of the room. Home key is D MINOR (ending resolves to D MAJOR).
Suno can't read sheet music, so every STYLE prompt spells the notes out in words
(and the order of the notes, up/down) - but you will get much better consistency
if you also follow the WORKFLOW below.

  M1  "THE KEEP"  (the castle's theme)
      Four slow, heavy notes descending:   D - C - Bb - A   (then a rest, then D again).
      Home instrument: PIPE ORGAN with low strings.  It's the bass line / countermelody of
      almost every zone and returns at double speed in the boss fights.

  M2  "THE STRANGER"  (the hero's theme)
      Rising and lonely:   A - D - F - E   (up a fourth, up a minor third, down a half step).
      Home instrument: SOLO CELLO (or French horn).  Quiet and questioning at first; each
      zone gives it a more confident voice; at the final boss it is a full brass declaration.

  M3  "THE TOLLING"  (bells - the castle's heartbeat)
      Three bell strikes, low - high - low:   D - A - D, spaced widely like a funeral bell.
      Always a different bell: church bell (graveyard), glass bells (chapel), clock chimes
      (underworks), muted/distorted (throne).

  M4  "THE CURSE"  (the villain / danger)
      A tritone stab (D against Ab) followed by a slow chromatic crawl downward:
      Ab - G - Gb - F.  Low brass, organ clusters, or detuned strings.  Whenever a boss or
      the Shadow Lord is near, this motif is under the music.

  M5  "DAWN"  (ending only)
      THE KEEP turned upside-down and into the major key:   D - E - F# - A,  rising, warm,
      finally resolving.  The Stranger (M2) plays along with it in D major.  Save this for
      the last track so it lands.

  TRANSPOSITION CHEAT SHEET  (the prompts below already use these)
      D minor (home) ....... M1 D-C-Bb-A     M2 A-D-F-E       M3 D-A-D
      G minor (Great Hall) . M1 G-F-Eb-D     M2 D-G-Bb-A      (waltz, 3/4)
      D dorian (Chapel) .... M1 D-C-B-A      M2 A-D-F-E       (B natural, not Bb)
      D major (save/stings/ending) .... M2 A-D-F#-E (up a fourth, up a major third, down a
                            whole step)   M1-as-lullaby D-C#-B-A   M5 D-E-F#-A

SUNO WORKFLOW FOR CONSISTENT THEMES
-----------------------------------
  1. Generate TITLE first (get a take where the 4-note organ theme M1 is
     clear and the cello answer M2 is audible).  Re-roll until it's right -
     this track is the "seed" for everything else.
  2. For every other track, use Suno's audio-upload / Cover / Extend
     features (names vary by version) with the title track (or a finished
     zone track) as the reference, set the audio-influence HIGH for
     close variations (intro, save, ending) and LOW/MEDIUM for new styles
     (bosses, underworks).
  3. Keep the same key and tempo family wherever possible: 60 / 90 / 120 /
     150 BPM (all multiples of 30) makes motifs line up when you crossfade.
  4. Suno can't loop perfectly: ask for a strong final chord on the tonic
     (the prompts do), then trim the file at a bar line and add a short
     fade/crossfade in any audio editor so the loop point is seamless.
  5. Generate 3-4 takes per track and keep the one where the motif is
     clearest.  Add "instrumental" / turn on Suno's instrumental toggle for
     everything below.
  6. Prompts avoid artist and game names on purpose (Suno rejects them).
     If your Suno version only takes 200 characters of style, use the SUNO SHORT line.
  7. Suno follows note names loosely.  If a take plays the wrong notes, keep the take's
     mood, then fix the theme by Extending/Covering the TITLE track, or hum/play the four
     notes into Suno's audio upload as the reference.
